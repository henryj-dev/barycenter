# ADR-SPOF — v1 운영 정책 (RTO / RPO)

날짜: 2026-08-20
상태: 확정

## 결정

v1 데이터 플레인은 **단일 장애점**이다. 아래 세 숫자는 랩에서 잰 SLA 가 아니다.
**v1 운영 정책**이다. 런북은 `docs/runbook-spof.md` 다.

| 항목 | 정책 |
|---|---|
| RTO (DP 호스트 손실 → 서비스 복구) | ≤ 15분. **수동** 페일오버. |
| RPO (설정 손실) | 0. 정본은 PostgreSQL. 아티팩트는 재생성. |
| PG 손실 시 RPO | ≤ 5분. PITR/스트리밍이 있을 때. |

페일오버는 콜드 스탠바이 + DNS 또는 상위 L4 다. **자동이 아니다.** 멀티 노드 HA 는
이 ADR 의 범위가 아니다.

## 왜 정책이지 실측이 아닌가

15분 안에 사람이 스탠바이로 돌리는 것은 운영 약속이다. CI 가 그 시간을 재지 않고,
재지 않은 값을 계약처럼 적지 않는다. 후보로 두지 않는다.

## 하지 않는 것

- 자동 페일오버
- 멀티 노드 HA
- 기존 세션 강제 종료
